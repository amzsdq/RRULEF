# H1 sample plan

## Purpose
Determine whether start-of-turn crash-insurance pre-arm is worth keeping when RRULEF already performs a verified final rearm.

## Primary variable
`start_of_turn_crash_insurance_prearm_enabled` only.

## Phase A — clean treatment samples
Collect at least 3 clean H1 turns before any promotion decision. Each sample must show:
- pre-arm WRITE_OK + STATE_OK;
- substantive useful work;
- active invocation closes before pre-arm due;
- final rearm WRITE_OK + STATE_OK and supersedes pre-arm;
- no overlap/duplicate evidence;
- following invocation supplies retrospective WAKE_OK;
- actual predecessor end -> next start idle gap is measured when direct timestamps exist.

A clean sample does **not** by itself demonstrate the recovery value of pre-arm; it establishes that the extra mutation does not destabilize normal continuation.

## Phase B — value test
Only after clean safety is established, register a separate bounded fault-injection experiment if needed. It must change one primary variable and must not deliberately corrupt durable state or create destructive duplicate side effects. Candidate: omit the final rearm in one explicitly registered non-destructive test turn while preserving the verified pre-arm, then observe whether the same canonical wakes from pre-arm without overlap.

This must not be performed under H1 itself because final-rearm omission would be a second changed variable.

## Promotion gate
Do not promote dual-arm merely because Phase A passes. Promotion requires either:
- observed natural final-rearm failure where pre-arm materially bounded recovery, or
- a separately registered bounded fault-injection PASS,
plus acceptable clean-turn overhead/utilization.

## Rejection gate
Reject or demote dual-arm if any of the following occurs:
- successor overlaps an active predecessor;
- final rearm frequently fails because of the extra control path;
- pre-arm remains authoritative after normal close;
- scheduler/control overhead materially reduces useful-work utilization;
- final-only continuation proves sufficiently reliable that pre-arm recovery value is negligible relative to its cost.

## Runtime-frontier separation
H1 is a scheduler/recovery experiment. RRULEF 600s runtime promotion remains a separate direct-duration evidence obligation; a sub-600 H1 clean sample may be valid H1 evidence but is not a 600s duration PASS.
